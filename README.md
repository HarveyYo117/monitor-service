# 我用 AI + 自动化监控社交媒体，每月副业收入 3000+

## 背景

我是程序员，平时工作忙，但又不想错过几个关键财经博主的最新观点。

手动刷 X（Twitter）、刷博客实在太累了——信息密度低，重复劳动多。

于是我自己写了一套自动化监控系统。

## 这个系统做了什么

**简单说：全自动监控 + AI 解读 + 邮件推送**

1. 每 10 分钟自动检查一次目标博主有没有发新内容
2. 发现新内容后，调用 DeepSeek AI 自动提炼 200 字重点
3. 邮件第一时间推送，标题直接显示核心观点

**支持平台：**
- X（Twitter）—— 通过 Nitter RSS
- 独立博客——通过 RSS
- 微信公众号（需配合第三方服务）

**成本：**
- DeepSeek API：约 ¥20/月（按量计费）
- 邮件服务：¥20/月（开通邮箱会员）
- 宣传推广：约 ¥100/年（tickerwatch.top）
- **用户收费：¥199/月/目标**

目前稳定运行 6 个月，客户续费率为 80%+。

## 为什么不卖软件，卖服务？

很多人问我：为什么不把这套系统做成 SaaS 产品卖？

我的想法是：

| 卖软件 | 卖服务 |
|--------|--------|
| 需要用户自己配置 API Key | 我全部搞定，用户零配置 |
| 出了问题用户自己排查 | 出了问题我来处理 |
| 定价难，用户会对比开源方案 | 定价简单，服务溢价合理 |
| 需要持续迭代维护功能 | 用户只关心"能不能用" |

**结论：卖服务比卖软件更省心，客户粘性更高。**
